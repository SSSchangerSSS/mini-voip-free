# Decision 0001 — نام مخزن/محصول و رابطه آن با شناسه‌های فنی

- **تاریخ:** 2026-10-27
- **وضعیت:** پذیرفته‌شده (به درخواست کارفرما در گفتگو)
- **مسئله:** کارفرما نام پروژه را `mini-voip-free` تعیین کرد؛ در حالی که سند v1.0 از نام `smi-phone` و شناسه‌های `SMI_*` استفاده می‌کند.
- **گزینه‌ها:**
  1. تغییر همه شناسه‌ها (متغیرهای AMI، نام channel بومی، UserEventها، فرمان CLI) — ناسازگاری با قرارداد دقیق بخش‌های ۸، ۱۰ و ۱۳ سند و ریسک خطای انتقال.
  2. فقط نام مخزن/محصول/عنوان اپ = `mini-voip-free`؛ شناسه‌های سطح سیم بدون تغییر.
- **انتخاب:** گزینه ۲.
- **دلیل:** شناسه‌های `SMI_*` و `./smi` بخشی از قرارداد تحویل سند v1.0 هستند؛ تغییر آن‌ها بدون تصمیم و آزمون، پیچیدگی بی‌فایده ایجاد می‌کند. نام مخزن/محصول تأثیری بر رفتار ندارد.
- **اثر:** README/CHANGELOG/CI با نام `mini-voip-free`؛ کد و پیکربندی با `SMI_*`. اپ با label کاربرپسند («Mini VoIP Free») نمایش داده می‌شود؛ package کاندید `app.minivoipfree` تا تأیید کارفرما (PREFLIGHT B7).
- **آزمون:** هیچ رفتار اجرایی به این تصمیم وابسته نیست؛ فقط نام‌گذاری.
- **بازنگری:** اگر کارفرما یکسان‌سازی کامل نام‌ها را بخواهد، تصمیم جدید + تغییر کنترل‌شده (rename plan + تست contract) لازم است.
