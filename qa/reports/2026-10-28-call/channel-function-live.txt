
[1;35m  -= Info about Function 'CHANNEL' =- [0m

[1;35m[Synopsis][0m
[1;36mGets/sets various pieces of information about the channel. [0m

[1;35m[Provided By][0m
[1;36mfunc_channel[0m

[1;35m[Since][0m
[1;36m1.2.0[0m

[1;35m[Description][0m
[1;36mGets/sets various pieces of information about the channel, additional [1;32m<item>[1;36m
may be available from the channel driver; see its documentation for details.
Any [1;32m<item>[1;36m requested that is not available on the current channel will return
an empty string.
[1;37mExample:[1;36m Standard CHANNEL item examples

 [1;37m; Push a hangup handler subroutine existing at dialplan
 ; location default,s,1 onto the current channel
 same => n,Set(CHANNEL(hangup_handler_push)=default,s,1)
 ; Set the current tonezone to Germany (de)
 same => n,Set(CHANNEL(tonezone)=de)
 ; Set the allowed maximum number of forwarding attempts
 same => n,Set(CHANNEL(max_forwards)=10)
 ; If this channel is ejected from its next bridge, and if
 ; the channel is not hung up, begin executing dialplan at
 ; location default,after-bridge,1
 same => n,Set(CHANNEL(after_bridge_goto)=default,after-bridge,1)
 ; Log the current state of the channel
 same => n,Log(NOTICE, This channel is: ${CHANNEL(state)})
 [1;36m
The following channel variables are available as special built-in dialplan
channel variables. These variables cannot be set or modified and are read-only.
[1;32m${CALLINGPRES}[1;36m: Caller ID presentation for incoming calls (PRI channels)
[1;32m${CALLINGANI2}[1;36m: Caller ANI2 (PRI channels)
[1;32m${CALLINGTON}[1;36m: Caller Type of Number (PRI channels)
[1;32m${CALLINGTNS}[1;36m: Transit Network Selector (PRI channels)
[1;32m${EXTEN}[1;36m: Current extension
[1;32m${CONTEXT}[1;36m: Current context
[1;32m${PRIORITY}[1;36m: Current priority
[1;32m${CHANNEL}[1;36m: Current channel name
[1;32m${UNIQUEID}[1;36m: Current call unique identifier
[1;32m${HANGUPCAUSE}[1;36m: Asterisk cause of hangup (inbound/outbound)
    [1;33mTechnology: PJSIP  Provided by: chan_pjsip[1;36m
    [1;37mExample:[1;36m PJSIP specific CHANNEL examples

     [1;37m; Log the current Call-ID

 ; Store the round-trip time associated with a
 ; video stream in the CDR field video-rtt
 same => n,Set(CDR(video-rtt)=${CHANNEL(rtcp,rtt,video)})
