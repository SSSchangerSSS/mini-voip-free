
[1;35m  -= Info about Manager Command 'MessageSend' =- [0m

[1;35m[Synopsis][0m
[1;36mSend an out of call message to an endpoint. [0m

[1;35m[Provided By][0m
[1;36mbuiltin[0m

[1;35m[Since][0m
[1;36m11.0.0[0m

[1;35m[Description][0m
[1;36mNot available[0m

[1;35m[Syntax][0m
[1;36mAction: MessageSend
[ActionID:] <value>
[Destination:] <value>
[To:] <value>
[From:] <value>
[Body:] <value>
[Base64Body:] <value>
[Variable:] <value>[0m

[1;35m[Arguments][0m
[1;36m
ActionID
    ActionID for this transaction. Will be returned.

Destination
    A To URI for the message. If Destination is provided, the To parameter can
    also be supplied and may alter the message based on the specified message
    technology.
    For backwards compatibility, if Destination is not provided, the To
    parameter must be provided and will be used as the message destination.
        [1;33mTechnology: PJSIP  Provided by: res_pjsip_messaging[1;36m
        The [1;34m'destination'[1;36m parameter is used to construct the Request URI for an
        outgoing message.  It can be in one of the following formats, all
        prefixed with the [1;34m'pjsip:'[1;36m message tech.
         
        [1;34mendpoint[1;36m - Request URI comes from the endpoint's default aor and
        contact.
        [1;34mendpoint/aor[1;36m - Request URI comes from the specific aor/contact.
        [1;34mendpoint@domain[1;36m - Request URI from the endpoint's default aor and
        contact.  The domain is discarded.
         
        These all use the endpoint to send the message with the specified URI:
         
        [1;34mendpoint/<sip[s]:host>>[1;36m
        [1;34mendpoint/<sip[s]:user@host>[1;36m
        [1;34mendpoint/"display name" <sip[s]:host>[1;36m
        [1;34mendpoint/"display name" <sip[s]:user@host>[1;36m
        [1;34mendpoint/sip[s]:host[1;36m
        [1;34mendpoint/sip[s]:user@host[1;36m
        [1;34mendpoint/host[1;36m
        [1;34mendpoint/user@host[1;36m
         
        These all use the default endpoint to send the message with the
        specified URI:
         
        [1;34m<sip[s]:host>[1;36m
        [1;34m<sip[s]:user@host>[1;36m
        [1;34m"display name" <sip[s]:host>[1;36m
        [1;34m"display name" <sip[s]:user@host>[1;36m
        [1;34msip[s]:host[1;36m
        [1;34msip[s]:user@host[1;36m
         
        These use the default endpoint to send the message with the specified
        host:
         
        [1;34mhost[1;36m
        [1;34muser@host[1;36m
          		
        This form is similar to a dialstring:
         
        [1;34mPJSIP/user@endpoint[1;36m
         
        You still need to prefix the destination with the [1;34m'pjsip:'[1;36m message
        technology prefix.  For example: [1;34m'pjsip:PJSIP/8005551212@myprovider'[1;36m.
        The endpoint contact's URI will have the [1;34m'user'[1;36m inserted into it and
        will become the Request URI.  If the contact URI already has a user
        specified, it will be replaced. 
         
        [1;33mTechnology: XMPP  Provided by: res_xmpp[1;36m
        Specifying a prefix of [1;34m'xmpp:'[1;36m will send the message as an XMPP chat
        message.

To
    A To URI for the message if needed for the message technology being used to
    send this message. This can be a SIP(S) URI, such as [1;34m'Alice
    <sip:alice@atlanta.com>'[1;36m, or a string in the format [1;34m'alice@atlanta.com'[1;36m.
    This parameter is required if the Destination parameter is not provided.
        [1;33mTechnology: PJSIP  Provided by: res_pjsip_messaging[1;36m
        The [1;34m'to'[1;36m parameter is used to specity the [1;34m'To:'[1;36m header in the outgoing
        SIP MESSAGE.  It will override the value specified in MESSAGE(to) which
        itself will override any [1;34m'to'[1;36m value from an incoming SIP MESSAGE. 
          		
        [1;33mTechnology: XMPP  Provided by: res_xmpp[1;36m
        Ignored

From
    A From URI for the message if needed for the message technology being used
    to send this message.
        [1;33mTechnology: PJSIP  Provided by: res_pjsip_messaging[1;36m
        The [1;34m'from'[1;36m parameter is used to specity the [1;34m'From:'[1;36m header in the
        outgoing SIP MESSAGE.  It will override the value specified in
        MESSAGE(from) which itself will override any [1;34m'from'[1;36m value from an
        incoming SIP MESSAGE. 
          		
        [1;33mTechnology: XMPP  Provided by: res_xmpp[1;36m
        Specifying a prefix of [1;34m'xmpp:'[1;36m will specify the account defined in
        [1;34m'xmpp.conf'[1;36m to send the message from. Note that this field is required
        for XMPP messages.

Body
    The message body text.  This must not contain any newlines as that
    conflicts with the AMI protocol.

Base64Body
    Text bodies requiring the use of newlines have to be base64 encoded in this
    field.  Base64Body will be decoded before being sent out. Base64Body takes
    precedence over Body.

Variable
    Message variable to set, multiple Variable: headers are allowed.  The
    header value is a comma separated list of name=value pairs.[0m
